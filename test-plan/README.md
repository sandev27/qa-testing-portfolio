# Test Plan – Demo E-Commerce Website

## Objective
To test the functionality and usability of a demo e-commerce website.

## Scope
- User Registration
- Login
- Product Search
- Add to Basket
- Checkout
- Order Confirmation

## Testing Types
- Functional Testing
- Regression Testing
- Exploratory Testing
- Usability Testing

## Entry Criteria
- Test environment available
- Test data prepared

## Exit Criteria
- Critical defects resolved
- Regression tests completed
