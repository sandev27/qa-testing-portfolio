# Playwright Automation

UI automation tests built using Playwright.

## Application Under Test

https://www.saucedemo.com

## Automated Scenarios

- Valid Login
- Invalid Login
- Locked User Login
- Verify Products Load
- Add Item To Cart
- Remove Item From Cart
- Checkout Flow
- Order Confirmation

## Tech Stack

- Playwright
- JavaScript
- VS Code
- Git
- GitHub

## Execute Tests

npm install

npx playwright test

npx playwright test --headed
